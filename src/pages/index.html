Why we built this

Real rinks, real hours, ranked honestly

Searching for a rink usually means a mix of out-of-date event pages and lists that cover the wrong side of the state. We built one directory that lists every public ice rink we can verify, from the business data the rinks themselves publish on Google.

Rinks are ranked by Google rating weighted by how many reviews sit behind it, so a 4.7 from 900 skaters beats a 5.0 from three. Nobody pays for a higher spot. When a detail is missing, the page says so instead of guessing.
